Telegram Mini App

FX Board

A dark-mode Telegram WebApp classifieds board for currency buy/sell intent, backed by FastAPI, PostgreSQL, Nuxt, and aiogram.

GitHub Documentation

Mini App Auth

Backend validation of Telegram WebApp initData, server sessions, CSRF protection, and required channel access checks.

Classifieds

Ads for USD, EUR, RUB, USDT, USDC, and AR with reports, moderation, audit logs, and seller notifications.

Production Shape

Docker Compose deployment, PostgreSQL migrations, bot worker, one-domain reverse proxy notes, and CI checks.

Classifieds, not custody

FX Board does not process payments, hold funds, execute trades, or act as escrow. Users are expected to describe real transaction facts and comply with applicable rules in their jurisdiction.
